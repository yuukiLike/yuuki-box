# RAG：检索、引用与资料更新

**RAG** 是 **Retrieval-Augmented Generation** 的缩写，中文为**检索增强生成**。做法是<mark class="key">检索相关资料，补充到模型上下文，再生成回答</mark>。

## 什么时候需要 RAG

模型的训练语料有时间边界，也未必包含内部文档。政策刚更新时，模型可能仍按旧规则回答；RAG 可以在提问时检索当前生效的原文，补充回答依据。

常见用途：政策与收费规则查询、内部手册问答、需要出处的产品咨询。

```text
准备：资料 → 分块并保留来源

问题 → 检索相关片段
问题 + 片段 → 模型 → 带出处的回答
```

本章为选读。用一条**虚构的产品政策**演示查询、引用与更新：导出文件可下载 14 天，随后改为 7 天。

需 Node.js ≥22.22 与 pnpm。本地脚本无额外依赖，负责检索和构造提示；回答由现有 Codex 或聊天模型生成。

## 1. 检索本地资料

在仓库根目录运行：

```bash
pnpm demo:rag "导出文件可下载几天？"
```

输出中的政策片段：

```text
[policy.txt#1]
演示笔记产品的导出保留政策（虚构）：版本 v1；生效日期 2026-11-01；导出文件可下载14天。
```

`policy.txt#1` 表示文件与片段编号，可与[政策原文](labs/knowledge/policy.txt)核对。终端还会列出其他匹配片段。

## 2. 交给模型回答

复制终端中 `[交给模型]` 后的完整提示，发送到现有 Codex 会话或聊天模型。

模型应根据资料回答，例如：

```text
按 v1（2026-11-01 生效），导出文件可下载 14 天。[policy.txt#1]
```

核对天数、版本和出处是否与原文一致。<mark class="key">检索提供依据，模型组织回答</mark>；仅有引用标记，不能证明结论正确。

## 3. 核对资料不足

换一个资料中没有的问题：

```bash
pnpm demo:rag "退款多久到账？"
```

预期：

```text
资料不足：没有匹配片段。
```

没有命中时脚本停止，不构造生成提示；命中片段无法回答问题时，提示也要求模型报告“资料不足”。

## 4. 更新资料与核对时效

将 [policy.txt](labs/knowledge/policy.txt) 改为：

```text
演示笔记产品的导出保留政策（虚构）
版本 v2；生效日期 2026-11-02
导出文件可下载7天。
```

重跑第一步的命令，将新提示发送到模型。预期回答类似：

```text
按 v2（2026-11-02 生效），导出文件可下载 7 天。[policy.txt#1]
```

<mark class="key">RAG 的时效取决于资料是否及时更新</mark>。本例由人工确认规则已生效，再更新文件；脚本每次重新读取资料，不自动判断日期。

- **来源**：保留发布机构或资料所有者的原文、出处与版本。
- **日期**：发布不等于生效；按问题所指日期和适用范围选版本。
- **更新**：旧版退出当前检索并留档；查询历史规则时使用对应版本。

若仍回答 14 天，先看命中片段：旧片段需刷新资料与索引；片段已更新，则检查回答是否遵循依据。正式系统可用定时任务或发布事件同步原文，并更新索引。

## 5. 换成实际资料

1. 用实际政策或手册替换[资料目录](labs/knowledge/)中的 `.txt`。用空行分段，每段不超过 300 字符，并附来源与生效日期。
2. 用原话、同义问法和资料外问题查询，记录 **问题 / 命中片段 / 回答 / 引用**；无依据时应报告“资料不足”。
3. 更新一条规则后重新提问，确认回答采用新版本。

关键词经常漏掉同义表达时，可加入 embedding（文本向量）语义检索；资料规模增大后再考虑向量索引。先验证资料能被找对、引用能支持回答。

<summary>实现与脚本检查</summary>

实现：[rag.mjs](labs/rag.mjs)。本例按关键词检索，使用三个函数：

| 部分 | 职责 |
| --- | --- |
| `loadDocuments` | 读取本地 `.txt` 资料 |
| `retrieve` | 按段分块、中文分词、按命中词数排序，最多返回两段，每段最多 300 字符 |
| `buildPrompt` | 合并问题、片段与引用要求；空结果返回 `null` |

资料随提示进入本次上下文；<mark class="key">RAG 不修改模型参数</mark>。

```bash
pnpm check:rag
```

检查中文检索、资料不足、引用、片段限制与资料更新；模型回答需另行核对。
