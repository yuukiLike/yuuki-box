# Windows 本地 AI：图片与音乐生成

**用自己的 Windows 电脑生成图片和音乐，再把模型、工作流和结果保存在本机。** 先用 Qwen Image 生成竹林画面，再用 ACE-Step 给它做一段配乐。两课共用 ComfyUI，分别保存 PNG 和音频。

这里沿用你之前提供的配置：**RTX 5060 Ti 16GB、i5-10400F、16GB DDR4-3200 内存、1TB 硬盘、500W 电源**。先用现有机器完成一次实验。

第一课使用 **ComfyUI Windows Portable + Qwen-Image-2.1-Turbo**。它属于 Qwen Image 系列，官方提供 8 步生成方案；本课选用量化权重来降低文件大小和内存压力。[Qwen 官方模型说明](https://huggingface.co/Qwen/Qwen-Image-2.1-Turbo)

第二课选择 **ACE-Step 1.5 Turbo**，把音乐风格描述与可选歌词变成音频。先做纯音乐，再试自己的中文短歌词；配套工作流使用 ComfyUI 原生支持的 AIO 整合文件。[ACE-Step 官方教程](https://docs.comfy.org/tutorials/audio/ace-step/ace-step-v1-5)

## 以第一课认识应用、模型和工作流

| 名称 | 在这次实验里是什么 | 保存在哪里 |
| --- | --- | --- |
| 应用 | ComfyUI，负责加载模型、组织计算和显示结果 | `ComfyUI_windows_portable` 文件夹 |
| 模型 | 图像生成模型、文本编码器、VAE 三份权重 | `ComfyUI\models` 下的对应子目录 |
| 工作流 | 一份 JSON，记录节点连接、模型文件名、提示词和采样设置 | 自己下载或导出的 `.json` 文件 |

可以把一次生成读成：

```text
提示词 → 文本编码器 → 图像模型逐步生成 → VAE 解码 → 保存 PNG
```

工作流不包含那些体积很大的模型文件。把 JSON 发给另一台电脑时，对方还要有兼容的 ComfyUI 和相同模型。本课的计算由本机程序执行，浏览器显示操作界面；下载完依赖和权重后，这份工作流不需要模型 API key。[ComfyUI 模型与工作流](https://docs.comfy.org/basic-concepts/models)

## 你的三个容量要分开看

| 硬件 | 用途 | 第一次怎么安排 |
| --- | --- | --- |
| 16GB 显存 | 存放 GPU 当前计算需要的权重、缓存与中间结果 | 第一课先生成一张 512×512 图片；第二课先生成一段 30 秒音乐 |
| 16GB 系统内存 | Windows、ComfyUI、模型加载与卸载时共用 | 关闭其他大型程序，保留系统管理的分页文件 |
| 1TB 硬盘 | 保存应用、模型、图片、音频与分页文件 | 检查剩余空间；第一课建议预留至少 60GB，第二课另留至少 20GB |

**16GB 内存和 16GB 显存不能当作一块 32GB 显存使用。** 模型在两者之间移动会带来额外开销。下载文件的大小也不等于运行时的峰值占用；具体能否顺利生成，需要在这台机器上观察。

两课按 **2026-10-29** 的官方文件和工作流编写，均附有可下载的入门工作流；尚未在这台 Windows 电脑上实测生成或耗时。每次只运行一个模型，从小图和短音乐开始，再比较提示词。
