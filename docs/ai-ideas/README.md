## 实验定义：输入、交付物与判定标准

选中一个方向后，写三行就能开始收敛：

```text
给它什么：一份错误记录、一段代码，或一个固定输入。
想拿回什么：一份候选 Issue、一组实验结果，或一份整理后的笔记。
怎样判断有用：能复现、输出正确、少做了重复工作，或下次能查回来。
```

比如“让 AI 自动优化代码”，先收成“固定一个纯函数的输入和输出，让它最多试三种改法，保留每次检查结果”。一轮做完，好不好玩、值不值得继续，都有东西可看。
