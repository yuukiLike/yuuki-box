## 比上一轮多挖到什么

1. **组合有层次。** 呈现、能力、执行和部署各需保证；共享滚动区域不代表执行对象同构，`launchCommand` 启动确认不代表完成。
2. **抽象有失效点。** Zed Agent crate 依赖应用体系，Grok 实例绑定会话；同名接口或独立目录不代表可随意抽走。
3. **复杂性可以减少。** 删除重复权威、限制并发、延后通用性可减少状态；托管部署或桥接主要改变承担者。
4. **极简保留关键事实。** 转写阶段、写入副作用和流终态影响下一步行动，不能抹掉。
5. **本地实现已推进。** 共享 runtime、工具循环、持久会话与 Whisper 已有代码，但<mark class="caution">真实 API/录音及端到端行为未验收</mark>。

第 1 项见 02/01，第 2 项见 03，第 3 项见 01，第 4/5 项见 04；不新增选型、应用改动或平台建设要求。
