# AI 搭子（同行者）

Side by Side · 和 AI 做朋友，一起想，一起做。

一起聊天、探索，也托付具体任务；AI 持续推进，把结果与需要决定的事带回来，在共同经历中形成自己的表达和判断。

从具体小事开始协作。

## 当前优先：Issue 自动化

先交一个<mark class="key">验收清楚的问题</mark>：读取、修复、验证、返修，最后交草稿 PR；跑通后再持续跟进。

| --- | --- | --- |

## 一起检查，接受纠正

交付后按[复现、验收与返工](../ai-practices/your-workflow.md)核对证据；需要第二份意见时，用[独立审查与有限返修](../ai-ideas/01-ideas-map.md#你的设想二另一个-ai-来审查代码)。
