# OpenAI API 额度怎么用：语音、音乐与多模态小项目

**先让额度留下一个自己愿意反复使用的成果：随口说话能变成笔记，学过的文章能听着复习，一段音乐能配上画面。** 本章把这些方向放到一起，每个方案都给出输入、调用路径和第一份成果。

领取入口、有效期与模型清单在[OpenAI API：额度、图片与语音](openai-api.md)。这里继续回答「领到以后做什么」，重点串起本站的语音教程、音乐 MCP 和本地配乐实验。

以下方案根据当前仓库重新整理，均为待试选题。官方能力核对日期：**2026-10-31**；本次只编写文档，未发起付费 API 调用。

## 语音：让输入和复习接起来

### 1 · 语音灵感箱：走两步，说清下一件事

适合突然想到一个功能、一个问题，暂时不想打开编辑器的时刻。

```text
录一段话 → 转写为文字 → 整理成灵感卡 → 自己确认 → 保存
```

先保留原始转写，再整理成「想解决的问题、目前已知、尚缺的信息、下一步」四项。没有说出的决定留空，方便以后接着讨论。

可以这样要求文本模型：

> 根据这段转写整理一张灵感卡。保留原话中的犹豫和未确定项，给出一个能在十分钟内验证的下一步，并引用对应原句。

第一轮录 3 段，检查专有名词、否定词和数字，再比较整理结果是否忠于原话。文件转写当前从 `gpt-transcribe` 开始；正在输入的麦克风音频另有实时转写流程。[录音转写](https://developers.openai.com/api/docs/guides/speech-to-text)

### 2 · 有声笔记：把一篇文章变成能听的讲解

选自己写过或有权处理的一篇笔记，先整理出一段约 90 秒的讲解稿，人工核对后再合成声音。公式、代码和链接改成听得懂的解释，同时在文稿里保留原文位置。

第一轮只比较两种讲法：「解释给刚入门的自己」和「用三个问题复习」。听完后，检查概念、英文术语和停顿，保存最终文稿及音频，后续修改时只重新生成改过的段落。

新接入要沿当前语音合成指引选择模型与接口。核对时，旧 `tts-1`、`tts-1-hd`、`gpt-4o-mini-tts` 已弃用，计划于 2027-01-06 停用；官方指向 `gpt-realtime-2.1-mini` 与 Realtime API，接入流程也随之变化。向他人提供生成语音时，标明 AI 合成。[语音合成与迁移说明](https://developers.openai.com/api/docs/guides/text-to-speech)

已有本地入门路径见[让 Yuuki 开口说第一句话](../tts/让-Yuuki-开口说第一句话.md)；云端与本地声音可以使用同一份讲解稿比较。

### 3 · 口答复习：解释完，再接一个追问

把本站的一小节资料作为依据，让助手每次只问一个问题。自己用语音回答，助手指出漏掉的条件，并根据该段资料追问；五轮后保存「我怎么答的、依据在哪、还缺什么」。

例如读完 KV Cache 后，先解释「为什么改前缀会影响复用」，再追问「只改末尾时有什么不同」。答案依据限于提供的资料，便于复核。

第一版可以拆成「录音 → 转写 → 文本判断 → 语音回答」，分别检查每一步。需要自然连续对话时，再选择 GPT-Live 或 Realtime：GPT-Live 可边听边说并把任务交给后端；Realtime 提供语音回合、会话状态和工具调用。[语音架构选择](https://developers.openai.com/api/docs/guides/audio)、[GPT-Live](https://developers.openai.com/api/docs/guides/live)、[Realtime](https://developers.openai.com/api/docs/guides/realtime)

第一轮检查三件事：能否听完我的话、打断后能否停止旧回答、最后的复习记录是否对应实际对话。结束练习时关闭会话并保存实际用量。浏览器接入由可信后端处理项目 Key，按对应 API 的连接流程建立会话。[GPT-Live 接入与结束会话](https://developers.openai.com/api/docs/guides/live)

## 音乐：从创作想法走到试听和画面

本章把 OpenAI 用在**编排草案、歌词与说明、配图和旁白**，再交给现有音乐工具生成或渲染音频。这样每一段调用都对应可检查的素材。

### 4 · 配乐草案：同一个场景，试听三个方向

例如想给「雨夜里读书的 Yuuki」配乐，可以先让文本模型提出三种版本：安静的钢琴、轻盈的电子、带留白的室内乐。每份草案写清时长、速度范围、主要乐器、情绪变化和结尾方式；需要歌词时另留一段自己的短歌词。

> 给这个场景设计三份 30 秒配乐草案。每份列出乐器、节奏、前中后三段的变化和结尾。保留我给的场景细节，标出需要试听才能决定的部分。

之后按[ACE-Step 首次配乐教程](../windows-local-ai/02-ace-step-music.md)在本地生成短音频，保持其他参数一致，比较三份草案的实际听感。OpenAI 额度用于前面的文本请求；ACE-Step 使用本地算力，其他供应商的音频服务按各自规则计费。本文没有验证 OpenAI 的专用歌曲生成接口。

**第一份成果：** 三份可复用的配乐描述、对应试听文件，以及「喜欢哪一处、下次只改什么」的记录。

### 5 · MIDI 讲解卡：让说明对应正在响的音符

沿用[声部之结](../ai-from-scaling/07-music-space-mcp.md)，先从 MIDI 解析实际的轨道、音高、起点与时值，再把选定小节的数据交给模型。让它解释「哪个声部先进入」「哪里有休止」「两次出现的节奏有什么相同」，配上一小段旁白。

```text
MIDI → 解析后的音符与小节 → 文字讲解 → 人工核对 → 旁白与可视化
```

先定位两处小节，独听对应声部，确认说明与数据一致。MIDI 解析、音符播放和空间渲染继续由本地音乐工具完成；模型负责基于这些数据讲解。

**第一份成果：** 两张带小节位置、数据依据和试听入口的讲解卡。普通 MP3/WAV 的音量包络可用于画面起伏；准确音符和声部沿用 MIDI 路径。

### 6 · 音乐照片短片：给一段音乐做一套视觉

选一段自己可使用的音乐，让模型先写出场景、配色与运镜草案，再生成封面或背景。需要前景、中景时，分别准备带透明通道的图层，检查尺寸、遮挡与风格后，交给[光之剧场](../ai-from-scaling/08-music-photo-mcp.md)导入和导出。

```text
音乐与主题 → 分镜草案 → 背景 / 透明图层 → 音乐 MCP 时间轴 → MP4
```

第一轮沿现有教程导出 4 秒，确认文件能打开、画面运动符合草案、音频与画面时间对齐。图片生成与编辑消耗 OpenAI API 用量；音乐播放、Three.js 渲染和 FFmpeg 导出在本地执行。可选旁白单独走语音合成。[图片生成与编辑](https://developers.openai.com/api/docs/guides/image-generation)

**第一份成果：** 一张封面、一套可继续编辑的图层，以及一个带声音的短片。

## 图片与日常：让生成结果可以找回、继续编辑

### 7 · 截图记忆库：问一句话，返回原图

给 20 张截图编号，让看图模型生成简短说明和可见文字，连同原图路径保存。以后输入「那个有粉色侧栏的设置页」，从这些说明里找候选，返回可以打开的原图。

第一轮用五种不同说法找已知截图，核对命中结果。图片说明只在新增或更换截图时重建，已有索引可以继续复用。具体社区来源与试做步骤见[截图记忆库](openai-api.md#community-ideas)。

### 8 · 学习漫画：同一个角色解释三个步骤

选「缓存命中 → 条件变化 → 缓存失效」这样的单一知识点，先核对三格分镜，再带着同一角色参考图生成画面。角色漂移时针对对应画面编辑；公式和代码可以在排版阶段加入。

第一轮检查知识点、角色和前后因果。保存参考图、分镜、提示词与最终图片，下一次就能接着做同系列。API 支持图片生成与编辑，已有参考图可以作为后续编辑的输入。[图片工作流](https://developers.openai.com/api/docs/guides/image-generation)

## 给每轮实验留一个停点

先选一个方向，用上表的小样本完成一轮。为每份成果保留四项记录：

| 记录 | 方便以后判断什么 |
| --- | --- |
| 输入素材与提示词 | 换模型或调整要求时能否比较 |
| 原始返回与最终成果 | 哪部分来自模型，哪部分经过修改 |
| 模型、用量与实际费用 | 这一轮值不值得继续扩大 |
| 一条下一步 | 下次接着改哪里 |

用量到 [Usage](https://platform.openai.com/usage) 核对，余额与到期时间到 [Billing](https://platform.openai.com/settings/organization/billing/) 查看。订阅赠额覆盖关联组织符合规则的 API 用量；用完后若仍有购买余额，会继续扣购买余额。具体领取和扣费规则见[官方赠额说明](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)。

**建议从「3 张语音灵感卡」开始。** 它能同时练到录音输入、转写、文本整理与保存结果，完成后再给其中一张卡加上语音回答。更想留下音乐作品，就沿「配乐草案 → 本地试听 → 封面与 4 秒短片」做完一条路径。
